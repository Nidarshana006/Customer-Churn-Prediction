# Customer Churn Prediction

Customer Churn Prediction is a Machine Learning project that predicts whether a customer is likely to churn based on customer-related features.

## Technologies Used

- Python
- Flask
- Machine Learning
- NumPy
- Scikit-learn
- HTML
- CSS
- JavaScript

## Project Structure

- `app.py` - Flask backend and prediction API
- `churn_model.pkl` - Trained machine learning model
- `feature_names.json` - Model feature information
- `index.html` - Frontend user interface
- `requirements.txt` - Python dependencies

## How It Works

1. User enters customer details.
2. Frontend sends the details to the backend.
3. The trained machine learning model processes the input.
4. The application predicts the customer's churn risk.
5. The prediction is displayed to the user.

## Project Goal

The goal of this project is to identify customers who may be at risk of churning and help businesses take suitable retention actions.
